# 康威生命游戏 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
康威生命游戏 (Conway's Game of Life)

### 1.2 产品描述
康威生命游戏的交互式网页实现，这是一种由数学家约翰·康威于1970年提出的细胞自动机。该应用提供了一个可视化模拟环境，用户可以通过简单的规则观察涌现出的复杂图案，支持自定义图案绘制、预设图案加载和双主题模式。

### 1.3 目标用户
- 数学和计算机科学爱好者
- 学习细胞自动机的教育用户
- 对涌现行为和模拟感兴趣的开发者
- 对零玩家游戏和视觉图案感兴趣的普通用户

## 2. 功能需求

### 2.1 核心模拟功能

#### 2.1.1 网格系统
- **网格大小**: 60x60 细胞（可通过代码配置）
- **细胞状态**: 二进制（存活/死亡）
- **边界条件**: 环形（边缘环绕）
- **数据结构**: Uint8Array 性能优化

#### 2.1.2 康威规则实现
1. **人口稀少**: 存活细胞邻居 < 2 时死亡
2. **正常存活**: 存活细胞邻居为 2-3 时存活
3. **人口过剩**: 存活细胞邻居 > 3 时死亡
4. **繁殖**: 死亡细胞邻居恰好为 3 时复活

#### 2.1.3 模拟控制
| 功能 | 描述 |
|------|------|
| 开始/暂停 | 切换模拟运行状态 |
| 单步 | 手动推进一代 |
| 速度控制 | 1-60 Hz 可调模拟速度 |
| 清空 | 重置网格为空状态 |
| 随机生成 | 随机填充细胞（默认 30% 密度） |

### 2.2 图案系统

#### 2.2.1 预设图案分类

**静物（静态图案）**
- 方块 (Block): 4细胞正方形
- 蜂巢 (Beehive): 6细胞图案
- 面包 (Loaf): 7细胞图案

**振荡器（周期图案）**
- 闪烁器 (Blinker): 周期2振荡器
- 蟾蜍 (Toad): 周期2振荡器
- 脉冲星 (Pulsar): 周期3振荡器，四重对称
- 十五邻 (Pentadecathlon): 周期15振荡器

**飞船（移动图案）**
- 滑翔机 (Glider): 对角线移动
- 轻量飞船 (LWSS): 水平移动

**枪（图案生成器）**
- 高斯帕滑翔机枪 (Gosper Glider Gun): 每30代发射一个滑翔机

**玛土撒拉（长寿图案）**
- R-五格拼板 (R-pentomino): 1103代后稳定
- 橡子 (Acorn): 5206代后稳定
- 顽强 (Diehard): 130代后消失

#### 2.2.2 图案放置
- 以光标位置为中心放置
- 放置前显示幽灵预览
- 自动边界检查

### 2.3 交互功能

#### 2.3.1 画布交互
| 操作 | 行为 |
|------|------|
| 点击 | 切换细胞状态 |
| 拖拽 | 绘制多个细胞 |
| 悬停（有图案） | 显示幽灵预览 |
| 悬停（无图案） | 高亮细胞 |

#### 2.3.2 显示信息
- 代数计数器
- 存活细胞数量
- 当前模拟速度

### 2.4 主题系统

#### 2.4.1 明亮主题
- 简洁现代的UI设计
- 渐变动画标题
- 柔和阴影和圆角
- 配色方案：白/灰配蓝色点缀

#### 2.4.2 矩阵主题
- 终端/赛博朋克美学/黑客帝国
- 等宽字体
- 绿色荧光发光效果
- 配色方案：黑色配绿色 (#00ff41) 点缀

#### 2.4.3 主题特定元素
两种主题均适配：
- 按钮样式和标签
- 画布颜色（网格、细胞、背景）
- 字体排版
- 面板样式

## 3. 技术需求

### 3.1 技术栈
| 层级 | 技术 |
|------|------|
| 框架 | Vue 3 (Composition API) |
| 语言 | TypeScript |
| 构建工具 | Vite |
| 样式 | CSS3 配合 CSS 变量 |
| 渲染 | HTML5 Canvas API |

### 3.2 架构

```
src/
├── components/          # Vue 组件
│   ├── ControlBar.vue   # 模拟控制栏
│   └── GameCanvas.vue   # 画布渲染
├── composables/         # 可复用逻辑
│   ├── useGameState.ts  # 游戏状态管理
│   └── useCanvasRenderer.ts  # 画布渲染逻辑
├── engine/              # 核心模拟引擎
│   ├── types.ts         # TypeScript 接口
│   ├── grid.ts          # 网格操作
│   ├── simulation.ts    # 康威规则
│   └── patterns.ts      # 图案定义
├── App.vue              # 根组件
├── main.ts              # 入口文件
└── style.css            # 全局样式
```

### 3.3 性能需求
- 目标：最高模拟速度下 60 FPS
- 使用 Canvas API 高效渲染
- 使用 TypedArrays 优化网格操作
- ResizeObserver 实现响应式画布

### 3.4 浏览器兼容性
- 支持 ES6+ 的现代浏览器
- Chrome、Firefox、Safari、Edge（最近2个版本）

### 4.2 控制栏元素
- **主按钮**: 开始/暂停模拟
- **次要按钮**: 随机生成、清空
- **图案选择器**: 带分类的下拉菜单
- **速度控制**: 滑块（1-60 Hz）

- **尺寸**: 响应式，最大 65vh 或 640px
- **宽高比**: 1:1（正方形）
- **网格线**: 浅灰色线条
- **细胞渲染**: 填充方块，带小边距

### 4.4 侧边信息面板
- **触发**: 右侧边缘悬停
- **内容**: 关于生命游戏的教育信息
- **主题**: 规则说明、涌现概念
- **语言**: 双语（根据主题切换中英文）

## 8. 附录

### 8.1 术语表
- **细胞自动机 (Cellular Automaton)**: 由按规则演化的细胞网格组成的离散模型
- **涌现 (Emergence)**: 从简单局部规则产生的复杂图案
- **代数 (Generation)**: 模拟规则的完整迭代一次
- **玛土撒拉 (Methuselah)**: 需要很多代才能稳定的小型初始图案
- **静物 (Still Life)**: 代际之间保持不变的图案
- **振荡器 (Oscillator)**: 经过固定代数后返回初始状态的图案
- **飞船 (Spaceship)**: 在网格上移动的图案

### 8.2 参考资料
- Conway, J. (1970). The Game of Life
- Gardner, M. (1970). Mathematical Games, Scientific American
